Chat

Multi-turn chat via client.chat.completions.create through the gateway — model selection pins a specific model or uses Auto Route for org pool routing.

Auto Route lets the gateway pick from your org routing pool. Org allowed models are every model this API key can call (from GET /v1/models). Your selection is remembered for all tabs.

File Upload + Analysis

      
Supported: PDF, DOCX, TXT, CSV (save legacy .doc as .docx). Max upload 64 MB per request. For reliable analysis, keep extracted text under ~10,000 characters — only text is sent to the gateway, not the raw file.
