## Codebase Patterns
- Services/ports: control plane :8100, gateway :8300; frontend Vite proxies /v1->8300 and /api->8100. chromadb test store at localhost:8001.
- Starlette routing is FIRST-MATCH-WINS. Duplicate @app.post(same path): the FIRST registered handler serves traffic; later ones are dead code. (Verified empirically.)
- responses_adapters.py is the canonical OpenAI translation layer. Reuse build_openai_error and coerce_chat_error_to_openai for the nested {"error":{message,type,param,code}} envelope. ID prefixes: resp_/msg_/fc_; usage remap prompt_tokens->input_tokens etc.
- patterns.redact_all + detect_pii share PII_PATTERNS and are intentionally conservative on phones (require a separator, to avoid matching order-ids/revenue). Extend with context-gating; do NOT remove the false-positive protection.
- The OUTPUT guard already downgrades "redact"->"flag" when the bytes didn't change (main.py ~1330). The INPUT/egress path lacks this honesty check — add it (story B1).
- /v1/embeddings currently does NOT scan/redact input — it only gates model/kill-switch (story B3).
- RAG ingest stores documents + metadata in the vector store and metadata flows into generator prompts; rag_redaction_enabled defaults False (story B5). RAG embed/grounding are fail-closed via assume_redacted=True — but that checks the FLAG not the bytes (story B1/B4).
- DETECTOR-COVERAGE pattern (B2): to broaden a CONTEXT-GATED patterns.py detector without new FPs, swap ONLY the trailing VALUE sub-pattern and keep the cue/prefix alternation intact; FP-safety is then preserved by construction (no cue ⇒ no match). Factor the value into a module const (e.g. `_BARE_PHONE_10_SPLIT`), reference it in BOTH the PII_PATTERNS entry and its masker, and have the masker `re.sub(r"\\D","",...)` before formatting so split separators don't break last-4 extraction. Bound the total digit count + trailing `\b` so a longer numeric id can't be partially masked.

- UNIFIED-EGRESS-REDACTOR pattern (B4): there is ONE deterministic egress redactor —
  `llm_router._redact_text_with_backstop(text, redacted_content)` — and the chat, operator-simulator
  (Module-1.1 IS the chat path), responses, /v1/embeddings, RAG-ingest, AND _scan_redact_metadata
  paths ALL funnel through it. `redacted_content` MUST be the firewall-authoritative `InputScanner.redact_pii`
  output (== `patterns.redact_all` + Tier-2 evidence-digit-spans). The backstop masks ONLY digit runs the
  firewall REMOVED (run absent from redacted_content but present on the wire) — so order-ids the firewall
  KEPT are never over-redacted and a separator-split phone the firewall masked can never ride raw
  (egress=truth). To add a new egress surface, call this helper with red_pii as the reference; never
  re-implement a blanket "mask all \d{7,}" backstop (it diverges + over-redacts). Fail-closed: if
  `_detected and redacted==text`, block (PII detected but unmaskable). bedrock_inference.py is ONLY
  model-selection helpers, NOT an inference path.

- UI-VERIFICATION pattern (D-stories): ship a DURABLE `scripts/playwright_*.mjs` (real customer POV)
  as the re-runnable gate, not just an ad-hoc MCP click-through. Run node FROM `frontend/` (playwright
  lives in frontend/node_modules); pass SHOT_DIR/E2E_REPORT env so artifacts land at repo-root runs/.
  Stack: Vite :8180 proxies /api→control:8100, /v1→gateway:8300. Login=POST /api/auth/token/
  (admin@zeroshield.io / Adm1n!Pass#2024); tokens in localStorage.auth_access/auth_refresh. Drive
  via waitForResponse on the real API call (assert status), assert the PARSED result + honest on-screen
  display, collect `pageerror` (hard-fail) — a UI claim is valid ONLY if the DOM/bytes reflect it
  (e.g. a created secret must NOT reappear in the listing; only `prefix...`). Time-based UI (inactivity)
  → `page.clock.install()` + `fastForward()` AFTER networkidle. Gateway resource IDs are UUIDs (match
  `[^/]+`, not `\d+`). Gate = `npm run lint && npm run build` (lint==test:unit) + the playwright run.

- Egress = truth: a redact/block verdict (or assume_redacted=True) is valid ONLY if the captured outbound bytes reflect it.
- Attestation must be byte-verified: if the scrubber is a no-op on a flagged span, fail closed (stronger scrub or block) — never forward/embed/store raw while attesting clean.

- MULTI-PROVIDER FAN-OUT pattern (D3): any gateway path that fans out to N org-configured external
  backends (vector providers, embedders, MCP servers) MUST bound EACH call (asyncio.wait_for) AND

  caller's timeout (the control admin proxy reads the gateway with a 10s budget — exceed it and the
  whole panel shows "gateway_unreachable"). Degrade a failed/slow backend to empty, never fail the
  whole aggregate. Tunable via env (RAG_LIST_COLLECTIONS_TIMEOUT default 4s). Bogus e2e fixture
  providers (pinecone->example.com) are a permanent landmine for sequential enumeration.
