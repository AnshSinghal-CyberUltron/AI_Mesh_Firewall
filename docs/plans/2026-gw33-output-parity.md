Card text (verbatim, `AI_MESH_MASTER_RUNBOOK_v3.1_CLEAN.docx`): *"GW33 — Output guardrail parity. Phase: Detection. **Depends on GW09, GW10, GW12.** Required by GW21, GW23. Objective: Restore v1's output guardrails on v2. Implementation work: IP and infrastructure leakage; exfiltration channels (zero-click images, links, HTML sinks, DNS labels); hallucination and grounding on a local model; human-review flag; REWRITE through a local model or a declared template (today REWRITE is mapped to REDACT); canary tokens checked on output. ## What shipped (offline)
- **Domain**: `Category.IP_LEAK/HALLUCINATION/CANARY`; `Disposition.REWRITE` (rank ALLOW < FLAG < REDACT < REWRITE < BLOCK); `Decision.review_required`/`codes`; pure `combine_decisions`; `Rule.rewrite_template`; `RuleCondition.allow_hosts`; `builtin_output_detector(rule)` (D-28: detector identity, never the category label); the closed code set (`edit_overlap_redacted`, `rewrite_template_missing`, `rewrite_unverified`, `final_check_unapplied`, `output_length_exceeded`, `canary_unavailable`).
- **Resolver** (the single authority): real REWRITE with the rule's declared template, overlap normalisation (D-7), review flag (`resolve/review.py`), identity join for built-in findings (D-32), unlocalised hallucination redact/rewrite falls closed to BLOCK. New AST gate `lint/check_single_authority.py` (rules A and B, frozen allow-list, stale-entry failure).
- **Detectors** (`detect/output/`): `IpLeakDetector`, `ExfilDetector`, `CanaryDetector`, `GroundingDetector` (lexical shipped; model mode capability-gated via `HallucinationCapable`). Every one stamps its platform rule id, carries `evidence=None`, and turns any failure into ONE `UNAVAILABLE` finding.
- **Egress**: byte-verified rewrites (`rewrite_verify`), REWRITE terminates on force-release (D-8), `canary` holdback class (only), whole-channel final check (`apply_final_check`), stateless per-delta canary overlap scan (D-23), typed terminal arms (`rewrite_unverified`, `output_length_exceeded`, `final_check_unapplied`), optional local-model rewrite proposer (template is the floor), multi-channel audit aggregate (`combine_decisions`), pass-through final check for flag-only rules.
- **Edge**: per-request composer (`edge/output_detectors.py`), canary injection (`edge/canary_inject.py`, D-19 semantics), response length backstop (`edge/output_length.py`, D-13), audit fields on the OUTPUT record (`review_required`, `review_queued`, `canary_checked`, `canary_leaked`, `bytes_action`, `codes`), 4 new error envelopes, MCP re-scan treats REWRITE like REDACT.
- **Plan**: `SUPPORTED_ACTIONS` += REWRITE, template validation (`plan/rewrite_template.py`), D-9 STRICT-only refusal keyed on detector identity, `allow_hosts`/grounding-mode/reserved-namespace validation, hash and document encoding only when non-empty (every existing plan keeps its `content_hash`), `requires: ["rewrite/1"]`.
- **Control plane**: `rewrite` leaves `_UNSUPPORTED_ACTIONS` (only `model_downgrade`, owner GW28, remains); per-org gate `rewrite_served_by_v2` (`V2_REWRITE_ORGS`, default none); five GW27-retired fields now mapped; platform `REWRITE_TEMPLATES`; built-in detector rows (`out_ip_leak`, `out_hallucination`, `out_exfil`, `out_canary`) at priority 200; `streaming_mode_for` promotion (D-20) reported as `streaming_mode_promoted`.

## Owner-visible deviations and open items
1. **Grounding on a local model: lexical shipped; model mode UNAVAILABLE until a backend advertises hallucination.** This is an open item against the card text with no owning card. It is NOT a GW10 deferral (GW33 depends on GW10). Follow-up card **GW33-F1** (model-backed grounding) is requested; owner acknowledgement requested.
2. **INCREMENTAL IP-redaction parity gap**: IP leak with redact/rewrite/block is STRICT_WITHHOLD-only (IPv6 and `host:port` are not holdable). Orgs choosing an enforcing IP action lose TTFT. Recorded follow-up: an IPv4/dotted-hostname-only INCREMENTAL hold class using the same stateless overlap scan.
3. **Obfuscated canary prefix in INCREMENTAL**: a plain-form canary is held to completion; an obfuscated one is detected and terminates the stream but a prefix may already be released (set `V2_CANARY_STRICT_ORGS` for zero exposure).
4. **L33-1 is live only for orgs in `V2_EXFIL_ORGS`** (default empty: no org is protected until the deployment owner enables it). Enablement runbook step below.
5. **Legacy IP rule id**: the design names `output_ip_leakage_*`, but the shipped publisher ids the row `fw-exfil-output` (`fw-{category}-{scope}`). `LEGACY_IP_RULE_PREFIX` is therefore `"fw-exfil-"`. Behaviour per D-2 is unchanged: inert in INCREMENTAL (as before this card), enforced in STRICT through the shim.
6. **Canary channel**: the injected slot reuses the pinned `message_content` channel instead of a new `TEXT_CHANNELS` entry (that table is a C21 contract).
7. **Setting names**: read as `AMF_<NAME>` (repo convention) or the bare `<NAME>`: `V2_REWRITE_ORGS`, `V2_CANARY_ORGS`, `V2_CANARY_STRICT_ORGS`, `V2_EXFIL_ORGS`, `V2_EXFIL_ACTION`, `V2_EXFIL_ALLOW_HOSTS`.
8. FOUND, NOT FIXED: GW09 detectors still rescan the whole buffer per delta (pre-existing, O(n^2) in stream length). Legacy-IP counter `legacy_ip_rule_in_use`/one-warning-per-install is exposed as `OutputDetectors.legacy_rule_ids` but not yet wired to a metrics series or log line at plan install.
9. The Django control tests (`control/.../tests/test_t01_rewrite_reject.py`, new `test_gw33_rewrite_gate.py`) could not be run here (no Django in the offline env); the map/publisher logic they exercise is covered by `gateway_v2/tests/plan/test_gw33_publish.py`.
