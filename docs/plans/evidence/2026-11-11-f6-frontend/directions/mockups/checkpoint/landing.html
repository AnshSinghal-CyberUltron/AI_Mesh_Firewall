Seven checkpoints on one route

Every request takes the same path. Each checkpoint has its own controls in the console and its own lines in the audit log.

1.1

Gateway ingress

Per-organisation keys, rate limits and request lineage for every call.

1.2

Policy

Rules that redact, block or watch prompts, compiled and versioned.

1.3

RAG and vectors

Scan documents on the way into your vector store and chunks on the way out.

1.4

MCP tools

Decide which agent may call which tool, with arguments checked first.

1.5

Model routing

Send each request to an approved model, with fallbacks you choose.

1.6

Kill switch

Take a model out of service in one action and see traffic move.

1.7

Output

Check responses for secrets, personal data and unsafe content.

Change one line. Keep your SDK.

The gateway speaks the OpenAI-compatible API. Point your client at it and the checkpoints apply.

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.your-company.internal/v1",    api_key=os.environ["ZEROSHIELD_KEY"],
)
# Same calls as before. Verdicts arrive as normal API errors.
client.chat.completions.create(model="gpt-4o-mini", ...)

Blocks look like errors your code already handles

A blocked prompt comes back as a content-filter error, so existing error handling still works.

One key per team or agent

Keys are scoped to an organisation and can be revoked without redeploying.
