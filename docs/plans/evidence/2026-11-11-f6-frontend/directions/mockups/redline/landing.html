One line in your client

The gateway is OpenAI-compatible. Point the base URL at it and every call is reviewed on the way in and out.

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.your-company.internal/v1",
    api_key=os.environ["ZEROSHIELD_KEY"],
)
