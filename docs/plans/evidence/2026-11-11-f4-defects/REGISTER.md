### R21: rollout of a publisher or gate change (fixed in PR 1)
- **Before:** an org's document changed only on its own save. After this release, after an `enforce` flip and after the rollback to `off`, every org that did not save kept its old rows.
- **Fix:** `control/ai_mesh_control/core/v2_plan_rollout.py`. `fingerprint()` hashes a probe document built by the running publisher plus every publish setting (`PUBLISH_SETTINGS`). `reconcile()` compares it with the fingerprint of the last complete sweep in Redis (`v2plan:rollout:fingerprint`): equal is one GET; different elects one runner (`SET NX`, TTL refreshed per batch), republishes every active org in keyset pages of 500, and records the fingerprint only if no org failed. `_store` raises a revision only when the body changed, so a repeat is harmless.
